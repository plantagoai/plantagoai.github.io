PlantagoAI Site

Deploy with `scripts/deploy.sh` (functions, Firestore rules, plantagoai.com and dagangilat.com; `pages` runs the GitHub Pages workflow). See `--help` and `--dry-run`.
Run locally with `scripts/run.sh` (the plantagoai.com dev server; `personal`, `all` and `test` modes). See `--help`.
